# 新链目录清场与血缘地图（2026-09-06 生效，命名终版）

> 规则：旧链（legacy 血缘）全部归档进 `legacy/`，一眼可辨、永不参与新迭代序列；
> 新链（zh-v2-rebuild 血缘）是一等公民正式序列，产物落位与 runtime 同源可见。
> 产品命名：现役 **mei-1.2-51m**，旧链归档保留 **mei-1.0-51m** 原名（只读证据）。

## 顶层布局

```
artifacts/mei-1.2-51m/              # 训练产物根（非 .local——训练成果不是临时文件）
├── exp-00300m/                     # ★ 新链 cycle 序列（第 1 轮；runs/corpus/products）
│   ├── runs/                       #   CPT/SFT 等训练 run（正式落位）
│   ├── corpus/                     #   语料与评测锁
│   └── products/                   #   阶段中间产物（头训练结果等）
├── legacy/                         # ★ 旧链归档区（只读证据，不参与新序列）
│   └── mei-1.0-51m/
│       ├── exp-00300m/             # 旧链 300M（语料/run/模型）
│       ├── exp-00600m/             # 旧链 600M
│       ├── _legacy/                # 旧 notebook 证据
│       ├── comparisons/            # 旧对比产物
│       └── synthetic-cpt-audit-v1/
└── pools/
    └── zh-v2-pool/                 # 现役语料池（raw/admitted/pools/layouts）

models/mei-1.2-51m/
├── architecture/                   # 架构规格（只读，参数契约 51,463,797）
│   └── tokenizer/TOKENIZER.json    # ★ 词表冻结指针（zh-24k-v3）
├── tokenizer/
│   ├── zh-24k-v3.model             # ★ 唯一现役词表
│   ├── tokenizer-zh-24k-v3-manifest.json
│   └── legacy/                     # 旧词表归档（v1/v2/manifest/vocab）
└── releases/
    ├── exp-00300m/                 # ★ 新链 releases（大版本在 product 名里，cycle 直属）
    │   ├── base/mei-1.2-51m-base-cpt300m-v1/     # 已注册 base 候选
    │   └── products/mei-1.2-51m-cpt300m-tool-sft-cq2-v1/  # 18MB cq2 产品容器
    └── legacy/mei-1.0-51m/         # 旧链 releases 归档（base/qat/sft/package）
        ├── exp-00300m/
        └── exp-00600m/
```

`.local/` 只留两类：`cache/`（cargo 构建缓存等可再生内容）与
`recovery/`（恢复辅助）；任何训练成果都不得再落 `.local`。

## 命名规则（新链迭代序列）

- **产品**：现役大版本 `mei-1.2-51m`；后续语料/架构大改 = `mei-1.3-51m` 等。
- **cycle 目录**：`exp-XXXm`（XXX=累计曝光量，5 位宽），第 N 轮 = `exp-{N×300}m`，
  直属 `artifacts/mei-1.2-51m/` 与 `models/mei-1.2-51m/releases/` 下，不带 `-vN` 后缀。
- **registry cycle_id**：保留 `exp-XXXm-v2` 形式作为血缘标记（与已完成 run 的
  run.json 证据绑定一致）；`cycle_lineage()` 读 registry 路由——
  zh-v2-rebuild → `exp-XXXm` 正式序列，legacy → `legacy/mei-1.0-51m/exp-XXXm`。
- **base 候选**：`models/mei-1.2-51m/releases/exp-XXXm/base/<id>`。
- **产品容器**：`models/mei-1.2-51m/releases/exp-XXXm/products/<id>`。
- **词表**：冻结指针（`TOKENIZER.json`）是唯一权威；旧词表只在 `tokenizer/legacy/`。

## 代码锚点（单一来源）

- `model-factory/common/_repo.py`：`ARTIFACT_ROOT`、`LEGACY_ARTIFACT_ROOT`、
  `cycle_lineage()`（registry 血缘路由）、`cycle_artifacts()`、`frozen_tokenizer_path()`。
- `model-factory/release/base_candidate_51m.py`：base 候选落位同样走 `cycle_lineage()`。
- 产品名校验（`mei-1.2-51m` 与归档 `mei-1.0-51m` 双接受）：
  python-sdk `mei_sdk/package.py`、browser-sdk `package.mjs`、
  rust `mei-sdk-core/src/package.rs`、`spec/model-package-v2.schema.json` 枚举。
- 其余代码不得硬编码产物路径；如需引用旧链证据，走 `LEGACY_ARTIFACT_ROOT` 常量。

## 约定

- `artifacts/**` 不进 git（.gitignore；训练产物以 receipt/RELEASE.json 中的
  sha256 证据绑定）。
- 旧链目录**只读**：需要回看旧产物时只做读取与对比，不写不改。
- 新链产物写入前遵守写一次原则（write-once + supersede 链）。
