# 新链目录清场与血缘地图（2026-09-06 生效）

> 规则：旧链（legacy 血缘）全部归档进 `legacy/`，一眼可辨、永不参与新迭代序列；
> 新链（zh-v2-rebuild 血缘）是一等公民正式序列，产物落位与 runtime 同源可见。

## 顶层布局

```
artifacts/                          # 训练产物根（非 .local——训练成果不是临时文件）
└── mei-1.0-51m/
    ├── legacy/                     # ★ 旧链归档区（只读证据，不参与新序列）
    │   ├── exp-000300m/            # 旧链 300M（语料/run/模型）
    │   ├── exp-000600m/            # 旧链 600M
    │   ├── _legacy/                # 旧 notebook 证据
    │   ├── comparisons/            # 旧对比产物
    │   └── synthetic-cpt-audit-v1/
    ├── cycles/                     # ★ 新链正式 cycle 序列
    │   └── exp-000300m/            # 第 1 轮（CPT 完成；runs/语料/评测锁）
    │       （第 2 轮 = exp-000600m，依此类推；目录名不带 -vN 后缀）
    └── pools/
        └── zh-v2-pool/             # 现役语料池（raw/admitted/pools/layouts）

models/mei-1.0-51m/
├── architecture/                   # 架构规格（只读，参数契约 51,463,797）
│   └── tokenizer/TOKENIZER.json    # ★ 词表冻结指针（zh-24k-v3）
├── tokenizer/
│   ├── zh-24k-v3.model             # ★ 唯一现役词表
│   ├── tokenizer-zh-24k-v3-manifest.json
│   └── legacy/                     # 旧词表归档（v1/v2/manifest/vocab）
└── releases/
    ├── legacy/                     # 旧链 releases 归档（base/qat/sft/package）
    └── zhv2/                       # ★ 新链 releases

        └── products/mei-1.0-51m-zhv2-cq2-v1/        # 18MB cq2 产品容器
```

## 命名规则（新链迭代序列）

- **cycle 目录**：`cycles/exp-XXXm`（XXX=累计曝光量），第 N 轮 = `exp-{N×300}m`。
- **registry cycle_id**：保留 `exp-XXXm-v2` 后缀作为血缘标记（与已完成 run 的
  run.json 证据绑定一致）；`cycle_artifacts()` 按 registry 血缘路由——
  zh-v2-rebuild → `cycles/exp-XXXm`，legacy → `legacy/exp-XXXm`。
- **base 候选**：`models/mei-1.0-51m/releases/zhv2/base/<id>`。
- **产品容器**：`models/mei-1.0-51m/releases/zhv2/products/<id>`。
- **词表**：冻结指针（`TOKENIZER.json`）是唯一权威；旧词表只在 `tokenizer/legacy/`。

## 代码锚点（单一来源）

- `model-factory/common/_repo.py`：`ARTIFACT_ROOT`、`LEGACY_ARTIFACT_ROOT`、
  `cycle_artifacts()`（血缘路由）、`frozen_tokenizer_path()`。
- 其余代码不得硬编码产物路径；如需引用旧链证据，走 `LEGACY_ARTIFACT_ROOT` 常量。

## 约定

- `artifacts/**` 不进 git（.gitignore；训练产物以 receipt/RELEASE.json 中的
  sha256 证据绑定）。
- 旧链目录**只读**：需要回看旧产物时只做读取与对比，不写不改。
- 新链产物写入前遵守写一次原则（write-once + supersede 链）。
