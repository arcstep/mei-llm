# 目录四分离与血缘地图（2026-09-06 终版）

> 原则：**源码、语料、过程、成果四分离**；旧链归档为 `mei-1.1-51m`（只读证据），
> 新链（zh-v2-rebuild 血缘）以 `mei-1.2-51m` 为一等公民正式序列；
> 隔离发布时 `models/` 目录（+ `src/architecture/` 源码）即发布面。

## 顶层布局

```
mei-llm/
├── src/                          # ★ 源码（item 1：模型架构、语料工厂、训练/编排/runtime）
│   ├── architecture/mei-1.2-51m/ #   现役架构（architecture.py/spec/heads/cq2…）
│   │                             #   旧链架构代码在 git 历史，不建 1.1 目录
│   ├── model-factory/            #   训练/编排/发布工厂
│   ├── corpus-factory/           #   语料工厂
│   ├── mei_llm/                  #   控制平面 CLI（python -m mei_llm，唯一正式入口）
│   └── platform/                 #   runtime 源码（rust/python-sdk/browser-sdk/_shared）
├── docs/                         # 文档（draft/ 为设计决策记录）
├── corpus/                       # ★ 语料（item 3：不按版本分，按语料自身组织；不进 git）
│   ├── pools/zh-v2-pool/         #   现役语料池（raw/admitted/layouts…）
│   ├── sft-suite/                #   现役 SFT 编译语料
│   └── eval-lock/                #   评测锁
├── cycles/                       # ★ 过程（item 4：runs + 中间产物 + 旧链全部证据；不进 git）
│   ├── mei-1.1-51m/              #   旧链归档（原 legacy；内部结构原样保留，receipt 路径不断）
│   │   ├── exp-00300m/  exp-00600m/  _legacy/  comparisons/  synthetic-cpt-audit-v1/
│   │   └── INDEX.md  LIFECYCLE.md  RELEASES.md
│   └── mei-1.2-51m/
│       └── exp-00300m/           #   runs/mei-1.2-51m/…  products/
├── models/                       # ★ 成果（item 5、6：词表 + runtime + 权重；发布面）
│   ├── mei-1.1-51m/              #   旧链成果归档
│   │   ├── tokenizer/            #     旧词表（v1/v2 等）
│   │   └── exp-00300m/{base,qat,sft,package}/  exp-00600m/…
│   └── mei-1.2-51m/
│       ├── tokenizer/            #   唯一现役：zh-24k-v3 + TOKENIZER.json 冻结指针
│       ├── runtime/              #   runtime 成果（wasm 构建产物 + manifest）
│       └── exp-00300m/{base, products}/   # 权重成果（00300m→02100m，5 位宽）
└── .internal/registry/           # 治理账本（cycles/artifacts/迁移路由表）
```

`.local/` 只剩 `cache/`（cargo 构建缓存等可再生内容）与 `recovery/`（备份）。
skills 体系已取消：训练经 `python -m mei_llm` 控制平面 + src/ 管线模块驱动。

## 命名规则

- **产品**：现役 `mei-1.2-51m`；旧链归档名 `mei-1.1-51m`（旧包内 baked 的
  `mei-1.0-51m` 字符串是写一次证据，保留不动；校验白名单三值全收）。
- **cycle 目录**：`exp-XXXm`（5 位宽），registry cycle_id 保留 `exp-000XXXm-vN`
  形式作血缘标记；`cycle_lineage()` 读 registry 路由——zh-v2-rebuild →
  `cycles/mei-1.2-51m/exp-XXXm`，legacy → `cycles/mei-1.1-51m/exp-XXXm`。
- **旧路径解析**：`.internal/registry/migrations/2026-09-four-domain.json` 是唯一
  路由表（含 `.local/artifacts/`、`artifacts/…`、`notebook/`、`sdk/…` 等历史前缀）；
  证据文件内容（指纹/哈希）一律不改，只改解析时路由。

## 代码锚点（单一来源）

- `src/model-factory/common/_repo.py`：`SRC_ROOT`、`CYCLES_ROOT`、
  `LEGACY_CYCLES_ROOT`、`CORPUS_ROOT`、`cycle_lineage()`、`cycle_artifacts()`、
  `frozen_tokenizer_path()`（指针 = `models/mei-1.2-51m/tokenizer/TOKENIZER.json`）。
- `src/mei_llm/registry/store.py`：治理账本读取 + 路径解析。
- 产品名校验（`mei-1.0-51m`/`mei-1.1-51m`/`mei-1.2-51m` 三值）：
  python-sdk `mei_sdk/package.py`、browser-sdk `package.mjs`、
  rust `mei-sdk-core/src/package.rs`、`spec/model-package-v2.schema.json`。
- 其余代码不得硬编码产物路径。

## 约定

- `corpus/**`、`cycles/**` 不进 git（哈希证据绑定于 receipts/CYCLE.json）。
- 旧链目录**只读**：只做读取与对比，不写不改。
- 新链产物写入前遵守写一次原则（write-once + supersede 链）。
- 隔离发布面 = `models/` + `src/architecture/`（权重、词表、runtime 成果与架构源码）。
