## 四种状态必须分开

**备选**表示还在选择、适配或审核。**合格候选**要求用途、检查范围与证据明确。**训练锁定**要求明确训练链、来源范围、split、tokenizer、配方、哈希和所需验证全部绑定。**实际使用**另由 run/receipt 和消费范围证明。Eval 使用“验收锁定／已用于评测”，不是训练使用。

旧包被冻结后又被方案取代，仍保留历史冻结事实，但不再是当前采用包。训练过也不意味着语义质量已合格。一个来源可服务不同代际；来源原文不按代际复制，代际清单引用精确包和范围。

## 尚未完成的整理

旧训练池 zh-v2-pool 及历史 SFT/Eval 保留原位置。当前修改了候选读取和混合采样的路径解析，以便不可变清单中的旧地址继续定位。逐运行消费明细、质量准入和新 CPT 打包不因目录整理自动完成。

本页和采用 JSON 是可读导航，不替代训练绑定，不自动选择“最大修订号”。未来新包也应按用途和日期存放，不能重新平铺回 pools 顶层。
